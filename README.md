# BookTalk

![License](https://img.shields.io/github/license/housaynraffea/booktalk)

**BookTalk** er et sosialt-nettverks-basert bok-anmeldingssystem hvor brukere kan *anmelde* bøker som de har lest (ved å sette på 1-5 stjerner og et *valgfritt beskrivelse* av anmeldelsen), og hvor andre brukere kan også *kommentere* på anmeldelsene. BookTalk er inspirert av letterboxd.

**BookTalk** er ment for alle som liker å lese bøker, eller som har lyst til å lese bøker.
